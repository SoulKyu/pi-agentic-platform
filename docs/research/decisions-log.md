# Brainstorming decisions log (pre-spec)

Started 2026-10-10. Feeds spec A (product brief + feature matrix), B (DESIGN.md), C (architecture), D (migration).

| # | Topic | Decision |
|---|---|---|
| 1 | Audience | Personal first, built to public-product standard (others install it); teams early on the roadmap. Data model carries `user_id` / `workspace_id` from day one, v1 = one owner. |
| 2 | Drivers | Must fix codebase sprawl and reliability/isolation. Whitepaper approach: language chosen on merit, TS kept if best. Not drivers: Next.js friction, runtime footprint. |
| 3 | Surfaces | Always-on server daemon + web UI / installable PWA (phone, push). No desktop shell in v1. |
| 4 | Inspiration | Per feature (existing and future): compare pi-web vs Orca (stablyai/orca) vs T3 Code (pingdotgg/t3code), adopt what they do better, our way. Feature source = local pi-web fork only. |
| 5 | Harness | Pi only, deep integration, no multi-harness adapter layer. |
| 6 | Data continuity | Pi sessions read in place (`~/.pi/agent/sessions`); pi-web-specific state (agents, triggers, tasks, pins…) imported once by a migration command; pi-web runs until cutover. |
| 7 | Backport | Lanes (`feat/lanes`, `pi-web-workspaces`, built by a Pi agent) Lots A+B are in scope; re-sync before specs C/D. |
| 8 | Install channels | Container image, native package/binary, npm/npx. Helm later (teams). Node is a runtime dependency in every channel (Pi needs it). |
| 9 | pi-web fate | Feature freeze after lanes Lot B; bugfixes only afterwards. |
| 10 | Auth | Local accounts (1 owner in v1) + password + WebAuthn passkeys, session cookies, API tokens (webhooks/CLI). OIDC with teams. Network exposure (reverse proxy / Tailscale) left to the user. |
| 11 | Brand direction | "Night Control" (E1): Mission Control grammar (colour = role, HUD mono uppercase labels, 2-3 px corners, 24 px background grid, outlined avatars, 2 px agent rule) with Aurora's flat colours and type (Manrope + JetBrains Mono). No gradients, no glow. Roles: violet = agent, orange = human / primary action, pink = needs attention, green = ok. Dark = E1 Night (`#110F18` bg, violet `#A78BFA`, orange `#FB923C`, pink `#EC4899`). Light = E1 Day Papier (`#FAF9F6` bg, warm stone greys, text/lines darkened for AA: violet `#6D28D9`, orange `#C2410C`, pink `#BE185D`; fills unchanged across modes). Mockups: `.superpowers/brainstorm/*/content/brand-directions-r1b.html`, `e1-light-r2.html`. |
| 12 | v1 scope additions (from refs) | All four groups in v1: **Lanes+** (fan-out compare across N lanes, forges beyond GitHub, issue tracker → lane), **Sessions+** (settle/snooze, FTS5 search over all Pi sessions, auto-resume on provider quota reset), **Security+** (`request_secret` one-use refs, precheck gate on triggers), **File editing** in-app. See `feature-matrix.md` §3 Q3. |
| 13 | Out of scope (stated, no objection) | Native mobile app, desktop shell, embedded browser / preview, SSH remote runtimes / multi-environment, vendor cloud relay, PTYs surviving daemon restart, Orca-style plugin host. |
| 14 | Default approval mode | **Auto-accept edits**: read + file edits run without asking; bash, network, non-read-only MCP, push ask for approval. Orthogonal to tool presets; overridable per session and per agent. Unattended runs keep the per-agent policies (sandbox, egress, denylist) on top. |
| 15 | Architecture approach | **A: TypeScript modular monolith + one `pi-host` worker per session.** Node 24 daemon (HTTP + one typed WS RPC, SQLite, outbox, auth, git, PTY) serving a React 19 + Vite SPA. Each session runs in a child process hosting the Pi SDK, speaking a JSONL protocol that is a superset of `pi --mode rpc` records (+ `navigate_tree`, `custom()`, platform calls). Policies and platform tools are in-process extensions of the worker calling back over stdio. Fallback per session to `pi --mode rpc` stays possible. Rejected: B (RPC child: loses navigate_tree/custom), C (Go: two runtimes, full rewrite, same losses as B). No Effect. |
| 16 | Session lifecycle (spec C §2) | Worker states cold → starting → idle ⇄ running → releasing (30 min idle) → cold; crash → cold, never auto-restarted. Transport = Node IPC (`fork`), records = `pi --mode rpc` shapes + pap records (`navigate_tree`, `custom_*`, `platform_call/result`, `policy_update`, `audit`, `health`, `ready`). Run end = `agent_settled` + `get_state` probe. Extension-initiated runs **accepted and audited** (refs kill them). Platform tools run in the daemon, caller identified by session type. |
| 17 | Persistence (spec C §3) | Three owners, no copies: Pi files read in place; platform state in one SQLite `~/.pap/state.db` (`node:sqlite`, WAL, synchronous=FULL, single writer, tables owned per module, forward-only additive migrations, snapshot before migration, `owner_id`/`workspace_id` on root entities); files for secrets (0600, never in DB), agent homes, attachments, worktrees, logs. Session identity = Pi file path; scanner keeps index + FTS5 by byte offset. Retention: runs unlimited, session_events 30 d, outbox 7 d, audit 12 months + explicit prune, logs 10 MiB × 10. `pap backup/restore`, scheduling via systemd timer. Spike: FTS5 in node:sqlite, initial scan cost. |
| 18 | Protocol & auth (spec C §4) | One WS `/ws` (requests + subscriptions + binary terminal frames, 1 MiB cap, `?proto=` gate → 426 reload). `defineMethod` in zod contracts with mandatory permission (`domain:read|operate|admin`), exhaustive handler table, `commandId` + receipts, fixed error codes. Cursor resume (≤128 events / 1 MiB else bounded snapshot), 50 ms delta coalescing, tool output fetched on demand, client connection supervisor. Auth: one-time setup URL in logs, password (`crypto.scrypt`) + passkeys (`@simplewebauthn/server`), cookie HttpOnly/Secure/SameSite=Strict 30 d sliding, hashed API tokens, Origin checks, login throttle. Bind 127.0.0.1 by default; HTTPS via Tailscale / reverse proxy or own cert. HTTP: **Hono** + `@hono/node-server` (chosen over bare `node:http` and Fastify), `ws` for upgrade. |
| 19 | Policy pipeline (spec C §5) | `pap-policy` extension loaded first in pi-host, rules compiled by the daemon (`policy_update` hot reload), fail closed. Stages: 00 exposure, 01 command denylist, 02 egress (+ MCP read-only), 03 approval (category × mode × taint), 04 run guard + budget, 05 bwrap + systemd scope, 06 secret redaction, 07 untrusted fencing → session **tainted** (new). Audit line per stage, never results. Categories read/edit/exec/network/external-write; tainted + exfiltration-capable always asks. Approval answers once / session / always (persisted, revocable) / deny. Policy profiles interactive / agent-thread / isolated-task chosen by the daemon. Platform ops declared with callers + exfiltration flag; `secret.request` new. Known v1 limit: host allowlist covers URL tools only; per-agent egress proxy on roadmap. |
| 20 | Automation & outbox (spec C §6) | Sources: schedule (RRULE + timezone), webhook (secret header + optional HMAC-SHA256, 64 KB streamed, Alertmanager/Grafana mapping, 60/min + 20 queued), feed, manual + dry-run, delegate/remind, quota reset (new). Gates: pause, budget, dedup, throttle, precheck (new). One transaction = fire row + task + outbox effect, 202 after commit. Runner: N slots, one task per agent thread, isolated tasks parallel, memory floor, single maxRunMs. Outbox: single worker, 30 s lease, 5 attempts, replay-safe vs process-bound (T3). Boot: recovery first; interrupted tasks **not** retried by default (`retryOnInterrupt` opt-in); missed schedules skipped by default (`catchUp: once` opt-in). Quiet hours: runs execute, pushes go to the digest. |
| 21 | Frontend (spec C §7) | React 19 SPA (Vite + React Compiler), no SSR. Layers runtime (socket, typed RPC, subscriptions + cursors) → zustand stores (one per stream, selector lint) → `features/<domain>` mirroring daemon modules (pure view-models tested without DOM) → `packages/ui` (E1 tokens, owned Radix primitives, AI components). Libs: TanStack Router, @tanstack/react-virtual, pi-web markdown pipeline + lazy shiki, CodeMirror 6 editor, xterm.js, cmdk, **tiptap composer** (chips @file / $skill / /command / @Agent). Diff renderer decided at spike. Keep Safari/iOS 16.4 floor, mobile ergonomics, shortcuts, internal i18n: **languages v1 = en + fr** (zh dropped). New: keybindings JSON, hand-written service worker, Orca feedback-timing rules, CI bundle budget. |
| 22 | Testing & quality (spec C §8) | Vitest everywhere (unit), integration with real SQLite + real git repos + real pi-host and a **scripted Pi custom provider** as the only fake (spike), Playwright e2e on Chromium + WebKit (~15 journeys), nightly Pi-compat job against latest SDK. Injected clock, explicit outbox drain, no sleeps, no coverage % target. Security tests: traversal, webhook auth/HMAC/size/dedup, fail-closed, taint, Origin. Blocking gates: 400 lines/file, eslint-plugin-boundaries, knip, reasoned disables, strict tsc, design-system lint, budgets (bundle, payload, idle worker RAM), supply chain (pinned, minimumReleaseAge 3 d, native build allowlist, Renovate). GitHub Actions. ESLint + Prettier. Dev isolation per worktree (`PAP_HOME` + derived port). AGENTS.md ≤ 150 lines, topic notes in `docs/agents/`, ADR per spec deviation. |
