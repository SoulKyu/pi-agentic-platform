| 15 | Architecture approach | **A: TypeScript modular monolith + one `pi-host` worker per session.** Node 24 daemon (HTTP + one typed WS RPC, SQLite, outbox, auth, git, PTY) serving a React 19 + Vite SPA. | 16 | Session lifecycle (spec C §2) | Worker states cold → starting → idle ⇄ running → releasing (30 min idle) → cold; crash → cold, never auto-restarted. | 17 | Persistence (spec C §3) | Three owners, no copies: Pi files read in place; platform state in one SQLite `~/.pap/state.db` (`node:sqlite`, WAL, synchronous=FULL, single writer, tables owned per module, forward-only additive migrations, snapshot before migration, `owner_id`/`workspace_id` on root entities); files for secrets (0600, never in DB), agent homes, attachments, worktrees, logs.
