M0

Spikes techniques

terminé

Huit expériences courtes et jetables pour lever les inconnues avant de concevoir.

Résultats
S1 worker Pi SDK · GOS2 provider scripté · GOS3 FTS5 · GOS4 RAM 156 MB/workerS5 diff → CodeMirrorS6 AI Elements · GOS7 trust store · GOS8 podman · fallback

M1

Walking skeleton

terminé · mergé

Un fil complet de bout en bout, volontairement minimal : setup, login mot de passe + passkey, session Pi dans un worker isolé, streaming, approbation des outils par pap-policy.

Livré
27 tâches, 1301 tests unitaires, 191 d'intégration, smoke du build en CI, 130 décisions archivées.
Sortie
Parcours setup → prompt → approbation → résultat validé sur les artefacts buildés.
Durée
M0 + M1 ≈ 20 h autonomes
M2

Sessions et UI d'extension

plan en cours

Toute l'expérience de session Pi sur le modèle worker.

Domaines
Steer / follow-up (file 128 msg / 32 MiB), navigate_tree, fork / clone, compaction, export HTML, auto-nommage, pagination, sorties d'outils à la demande, deltas regroupés 50 ms, brouillons, minimap ; tous les dialogues d'extension (select, input, editor, réponses session / toujours), barre de statut et boutons command:, widgets, panneaux custom(). Libération des workers inactifs (30 min), scopes systemd.
Dépend de
M1
Sortie
Comportements D01 et D18 de pi-web reproduits en tests d'intégration ; une extension ou un worker qui plante ne fait jamais tomber le daemon.
Estimation
25–35 h (provisoire)
