# UX-2: previews of what an agent serves, and rich replies Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A session in a box or an agent thread starts a supervised web server in its VM, and the owner opens it in one click in a Preview pane served from a separate untrusted origin; replies render Mermaid, math, the box's own images and sandboxed HTML artifacts.

**Architecture:**
- **The untrusted origin (kernel).** A second listener (`kernel/http/preview/`) on the preview port serves only `/p/<token>/` (a service, through its tunnel) and `/a/<token>/` (an artifact the daemon read from the transcript). It strips cookies and credentials both ways, never follows a redirect, adds the sandbox CSP and the other headers to every answer, and keeps the bounds. Every answer carries a sandbox CSP whose fetch directives name the preview origin (plus, for a networked session, its egress hosts frozen at mint): a page reaches no network its session could not (decision 139). The token store (`modules/previews/tokens.ts`) holds capability tokens in memory, with leases. The app refuses `Sec-Fetch-Site: same-site|cross-site` where browsers send it and gains `frame-src <preview origin>`; every cookie-authenticated GET route is side-effect-free or nonce-bound (a route-table test).
- **The guest (pi-host).** A service supervisor (`guest/services/`) runs `preview.start`'s command with the session shell's own bwrap argv (`bwrapVmArgv`, reused), checks that the port belongs to the service's process tree, keeps 200 log lines, and opens tunnels. A service without network is reached through a helper started inside its network namespace only (`nsenter --net` plus socket hand-off).
- **The tunnel (protocol 4).** A `tunnel` hello role carrying a slot, `tunnel_open` on the guest link, `TunnelFrame`s with a 1 MiB window both ways, mirroring B2's terminals.
- **The previews module (daemon).** A registry of services per box (fed by `svc.*` guest ops and `service` reports, cleared when the box stops), the platform ops `preview.start` and `preview.stop`, the `previews` stream, and the `previews.*` RPCs (`open` mints a token, browser only).
- **The web.** A `preview` item kind in the untrusted frame (`SandboxedFrame`, no `allow-popups`), a strip above the composer, a Preview entry in the phone switch, service lists on the project and agent pages, and a pap-origin window for OPEN IN A NEW TAB. Rich replies extend UX-1's reply seams after UX-1 merges (rebase point RB); a Mermaid diagram is an `<img>` of a `blob:` SVG and every math or diagram box is paint-contained (decision 139).

**Tech Stack:** TypeScript (erasable), Node 24 (`node:http`, no new relay dependency), zod 4 contracts, Hono, SQLite untouched, React 19, Tailwind 4 tokens, react-markdown 10 + remark-gfm + remark-math, KaTeX, Mermaid, vitest + happy-dom, Playwright (e2e only), Kata (local suite).

- **Module boundaries.** A daemon module imports only `@pap/contracts`, `kernel/` and other modules' `index.ts`. The listener is kernel (`kernel/http/preview/`): it reaches tokens and tunnels through its `grantOf` port. pi-host imports `@pap/contracts/pi-host`: the guest-side schemas (`preview-service.ts`, `tunnel-frames.ts`, `box-service-ops.ts`) are exported from `pi-host-index.ts`; the RPC methods (`previews-methods.ts`) from `index.ts` only.
- **Every RPC method declares a permission** in its domain file, an idempotency row in `methods-idempotent.ts`, and an `m14-classes.ts` row. Handlers decode, call one service method, map typed errors.
- **Tokens only** (no raw colour, no `[…]` value, no restyling of `@pap/ui` primitives). `70vh` is a new `@utility max-h-artifact` in `packages/ui/src/utilities.css`.
- **Code style.** Erasable TS; relative imports keep `.ts`; the only ESLint directive is `eslint-disable-next-line <rule> -- <reason>`.
- **Time and isolation.** Daemon and guest timers go through the kernel `Clock` / `GuestClock`; web tests use fake timers; no sleeps (`vi.waitFor` with a timeout, events). Tests never touch `~/.pi/agent` or `~/.pap`, never call a real LLM, never use the network, never reach the real pap-vmd (`PAP_TEST_VMD_SOCKET`, `testing/box-bed.ts`), and never use ports 7777, 7778, 7791 to 7794, 30141, 8090, 4040, 18022 or 18023: every listener in a test binds port 0.
- **Literal characters.** Never type a bidi, zero-width or line-separator character; build them with `String.fromCodePoint(...)`. Copy uses `·` (U+00B7) and `« »` only.
- **Safari 16.4 floor.** No CSS nesting, no `light-dark()`, no RegExp `v` flag. Relied on and present at 16.4: iframe `sandbox` and the CSP `sandbox` directive, CSP fetch directives naming explicit origins (the plan fix ran the service CSP in WebKit, Chromium and Firefox: UX2-R53), `contain: paint` (Safari 15.4), `referrerpolicy` on iframes, `X-DNS-Prefetch-Control` (Chromium only; harmless elsewhere). `Sec-Fetch-Site/Mode/Dest` shipped in Safari 16.4, but browsers send them only to potentially trustworthy origins (`https:`, `localhost`, loopback): on `--insecure-http` LAN mode none is sent and the T2 refusal never fires (UX2-R9, decision 139).
- **Logs** never carry a capability token (hash `t:<12 hex>` only, field name `ref`), raw service output (only through `previews.logs`, redacted), or a raw upstream answer.
- **Copy** never overstates safety: no "isolated" or "safe" claim about a preview; the docs name what a preview page can still do (Known limits, UX2-R88).

**DESIGN.md:**
- The untrusted frame is §2's dashed attention frame with the `UNTRUSTED · <source>` label, drawn outside the iframe (`SandboxedFrame`). Its label never sits inside the page.
- Buttons are mono capitals (`label-hud`), 44 px under a coarse pointer, labelled tooltips (no `title` except on the iframe, which the lint exempts).
- Live regions are polite; a failed service is a polite status line, never an alert (it is not the result of the owner's last action).

/** A capability token of the untrusted origin (spec §4): 32 random bytes in base64url without padding. */
export const PREVIEW_TOKEN = /^[A-Za-z0-9_-]{43}$/;
/** The longest request target the listener reads; a longer one is a bare 404. */
export const MAX_TARGET_CHARS = 8192;

export type PreviewTarget =
  | {
      readonly kind: "service" | "artifact";
      readonly token: string;
      readonly prefix: string;
      readonly rest: string;
    }
  | {
      readonly kind: "slash";
      readonly of: "service" | "artifact";
      readonly token: string;
      readonly location: string;
    };

// Controls, space, DEL, a backslash and a fragment never belong in a request target the browser sends.
const REFUSED_CHARS = /[\0-\x20\x7f\\#]/;
const SHAPE = /^\/([pa])\/([^/?]*)(\/[^?]*)?(\?.*)?$/;

/**
 * The request target of the untrusted listener: `/p/<token>/<rest>` for a service, `/a/<token>/<rest>` for an artifact.
 * `rest` keeps its query and its percent-encoding byte for byte (the service parses it, never pap). `/p/<token>` with no
 * slash after it is `slash`: the listener answers a redirect to `/p/<token>/` so relative links resolve under the prefix.
 * The token is matched raw: an encoded token is not a token. Anything else (absolute or authority form, `*`, another
 * prefix, a double slash, a refused character, a target over 8 KiB) is null, which the listener answers with a bare 404.
 */
export function parsePreviewTarget(raw: string | undefined): PreviewTarget | null {
  if (raw === undefined || raw.length === 0 || raw.length > MAX_TARGET_CHARS) return null;
  if (REFUSED_CHARS.test(raw)) return null;
  const match = SHAPE.exec(raw);
  if (match === null) return null;
  const [, letter, token = "", path, query = ""] = match;
  if (!PREVIEW_TOKEN.test(token)) return null;
  const prefix = `/${letter}/${token}`;
  const kind = letter === "p" ? "service" : "artifact";
  if (path === undefined) return { kind: "slash", of: kind, token, location: `${prefix}/${query}` };
  return { kind, token, prefix, rest: `${path}${query}` };
}
```

import type { IncomingHttpHeaders, OutgoingHttpHeaders } from "node:http";

/**
 * Hop-by-hop headers (RFC 9110 §7.6.1) and every header that would carry pap's identity, a capability or a client address
 * to the service. `Cookie` and `Authorization` never reach the VM (spec §4); `Referer` would carry the capability URL.
 */
const DROPPED_REQUEST: ReadonlySet<string> = new Set([
  "cookie",
  "authorization",
  "proxy-authorization",
  "referer",
  "host",
  "connection",
  "keep-alive",
  "proxy-connection",
  "te",
  "trailer",
  "transfer-encoding",
  "upgrade",
  "expect",
  "http2-settings",
  "forwarded",
  "x-real-ip",
]);

/**
 * The only headers of a service's answer the browser gets (UX2-R52, red team I10): what describes the body, its caching
 * validators and the page's own CORS answers. Everything else is dropped, so a header no browser knew of when this was written
 * (cookies, credentials prompts, device-bound sessions, client hints, storage access, reports, `Link` preconnects, HSTS,
 * `Alt-Svc`, `Clear-Site-Data`, `Refresh`, a policy of its own) never acts on pap's host. `Location` is rewritten apart.
 */
const KEPT_RESPONSE: ReadonlySet<string> = new Set([
  "content-type",
  "content-length",
  "content-encoding",
  "content-language",
  "content-disposition",
  "content-range",
  "accept-ranges",
  "etag",
  "last-modified",
  "vary",
  "date",
  "access-control-allow-methods",
  "access-control-allow-headers",
  "access-control-expose-headers",
  "access-control-max-age",
]);

/** The names a `Connection` header lists are hop-by-hop too (RFC 9110 §7.6.1). */
function connectionNames(value: string | string[] | undefined): Set<string> {
  const names = new Set<string>();
  for (const part of [value ?? []].flat().join(",").split(","))
    if (part.trim() !== "") names.add(part.trim().toLowerCase());
  return names;
}

const isForwarding = (name: string): boolean => name.startsWith("x-forwarded-");

export interface RequestCleaning {
  /** The service's port in its VM: the `Host` it is sent. */
  readonly port: number;
  /** `/p/<token>`: the path the browser sees in front of the service's own paths (`X-Forwarded-Prefix`). */
  readonly prefix: string;
  /** A WebSocket upgrade keeps `Upgrade: websocket` and its `Sec-WebSocket-*` headers. */
  readonly websocket: boolean;
}

/** The request as the service gets it (spec §4): no cookie, no credential, no referrer, no client address. */
export function cleanRequestHeaders(
  incoming: IncomingHttpHeaders,
  input: RequestCleaning,
): OutgoingHttpHeaders {
  const listed = connectionNames(incoming.connection);
  const out: OutgoingHttpHeaders = {};
  for (const [name, value] of Object.entries(incoming)) {
    if (value === undefined || DROPPED_REQUEST.has(name) || listed.has(name) || isForwarding(name)) continue;
    out[name] = value;
  }
  out.host = `127.0.0.1:${input.port}`;
  out["x-forwarded-prefix"] = input.prefix;
  if (input.websocket) {
    out.connection = "Upgrade";
    out.upgrade = "websocket";
  } else {
    // One tunnel per request: the service closes after its answer, so no idle connection holds a tunnel.
    out.connection = "close";
  }
  return out;
}

/** Every answer of the untrusted origin carries these, a relayed one or the listener's own 404 (spec §4). */
export function untrustedHeaders(csp: string): Record<string, string> {
  return {
    "content-security-policy": csp,
    "referrer-policy": "no-referrer",
    "cache-control": "no-store",
    "x-content-type-options": "nosniff",
    "x-dns-prefetch-control": "off",
    "access-control-allow-origin": "*",
  };
}

export interface ResponseCleaning {
  readonly prefix: string;
  readonly port: number;
  /** The path of the request this answers (without its query), as the service saw it: a relative `Location` resolves against it. */
  readonly requestPath: string;
  readonly csp: string;
}

/**
 * The answer as the browser gets it: the allowed headers of the service, a `Location` only when it stays inside the
 * preview, then pap's own. A `401` keeps its status and loses `WWW-Authenticate` (no credentials prompt over pap's tab).
 */
export function cleanResponseHeaders(
  incoming: IncomingHttpHeaders,
  input: ResponseCleaning,
): OutgoingHttpHeaders {
  const listed = connectionNames(incoming.connection);
  const out: OutgoingHttpHeaders = {};
  for (const [name, value] of Object.entries(incoming)) {
    if (value === undefined || !KEPT_RESPONSE.has(name) || listed.has(name)) continue;
    out[name] = value;
  }
  const location = typeof incoming.location === "string" ? rewriteLocation(incoming.location, input) : null;
  if (location !== null) out.location = location;
  return { ...out, ...untrustedHeaders(input.csp) };
}

const MAX_LOCATION_CHARS = 8192;
const BASE = "http://preview.invalid";
const OWN_HOSTS: ReadonlySet<string> = new Set(["127.0.0.1", "localhost", "[::1]"]);

/**
 * A redirect from the service: pap never follows it (spec §4). A target inside the same preview comes back under its
 * prefix; any other (another origin, a scheme-relative URL, a path out of the prefix, a malformed value) is dropped, so
 * the browser stays on the 3xx body and no header sends the frame to another host.
 */
export function rewriteLocation(
  location: string,
  input: Pick<ResponseCleaning, "prefix" | "port" | "requestPath">,
): string | null {
  if (location.length === 0 || location.length > MAX_LOCATION_CHARS || /[\0-\x20\x7f\\]/.test(location))
    return null;
  let url: URL;
  try {
    // A path-absolute target names the service's own root, which the browser sees under the prefix.
    url =
      location.startsWith("/") && !location.startsWith("//")
        ? new URL(`${input.prefix}${location}`, BASE)
        : new URL(location, `${BASE}${input.prefix}${input.requestPath}`);
  } catch {
    return null;
  }
  const tail = `${url.search}${url.hash}`;
  if (url.origin === BASE)
    return url.pathname.startsWith(`${input.prefix}/`) ? `${url.pathname}${tail}` : null;
  const own = url.protocol === "http:" && OWN_HOSTS.has(url.hostname) && url.port === String(input.port);
  return own ? `${input.prefix}${url.pathname}${tail}` : null;
}

/** The only headers of a service's `101 Switching Protocols` the browser gets: the handshake, nothing else (no cookie). */
const UPGRADE_KEPT: readonly string[] = [
  "sec-websocket-accept",
  "sec-websocket-protocol",
  "sec-websocket-extensions",
];

/** The head of a relayed WebSocket handshake, as raw lines: `Upgrade` and `Connection` fixed, the handshake headers copied. */
export function upgradeHead(incoming: IncomingHttpHeaders): string {
  const lines = ["HTTP/1.1 101 Switching Protocols", "Upgrade: websocket", "Connection: Upgrade"];
  for (const name of UPGRADE_KEPT) {
    const value = incoming[name];
    if (typeof value === "string" && !/[\r\n]/.test(value)) lines.push(`${name}: ${value}`);
  }
  return `${lines.join("\r\n")}\r\n\r\n`;
}

/**
 * A refusal written on a raw upgrade socket (no `ServerResponse` exists there): status line, pap's headers, no body. A
 * service that answers an upgrade with anything but `101` gets `rawRefusal(502)`: its own status, headers and body never
 * reach the socket (UX2-R52).
 */
export function rawRefusal(status: 403 | 404 | 413 | 502 | 503, csp: string): string {
  const reason = {
    403: "Forbidden",
    404: "Not Found",
    413: "Payload Too Large",
    502: "Bad Gateway",
    503: "Service Unavailable",
  }[status];
  const headers = Object.entries({ ...untrustedHeaders(csp), "content-length": "0", connection: "close" });
  return `HTTP/1.1 ${status} ${reason}\r\n${headers.map(([name, value]) => `${name}: ${value}`).join("\r\n")}\r\n\r\n`;
}

  return usable.length === 0 ? "'none'" : usable.join(" ");

/** `ws://` for `http://`, `wss://` for `https://`: CSP3 never lets an `http:` source match a WebSocket URL. */
export const socketOriginOf = (origin: string): string => origin.replace(/^http(s?):/, "ws$1:");

/** One source a networked service's page may reach: a scheme, a host (or `*.` and a name) or an IPv4, an optional port. */
const SOURCE = /^(?:https?|wss?):\/\/(?:\*\.)?[a-z0-9-]+(?:\.[a-z0-9-]+)*(?::\d{1,5})?$/;
const SCHEMES = ["http", "https", "ws", "wss"] as const;
/** The hosts of one page's CSP stop at this many characters; the entries past it are left out (a stricter page, never a wider one). */
export const MAX_HOST_SOURCE_CHARS = 8192;

/** Loopback names and addresses: the egress proxy never reaches them (`blocked_address`), so neither does a page. */
const isLoopback = (host: string): boolean =>
  host === "localhost" || host.endsWith(".localhost") || /^127\.\d{1,3}\.\d{1,3}\.\d{1,3}$/.test(host);

/**
 * Decision 139: a networked service's page reaches, in the owner's browser, what its session's egress list lets the service
 * reach, read from the daemon's records when the token is minted and frozen in its grant. Each entry is parsed by the proxy's
 * own parser (`tryParseHostEntry`): `host` and `*.name` become the four schemes on their default ports (80 and 443, the ports
 * the proxy allows a bare entry), `host:port` the four schemes on that port. Left out: an IPv6 literal (no CSP form), a loopback
 * name or address, and any entry that names one of pap's own hosts (any port), so no list ever opens pap's origins to a page.
 */
export function hostSources(entries: readonly string[], ownHosts: readonly string[]): string[] {
  const own = ownHosts.map((host) => host.toLowerCase().replace(/^\[|\]$/g, ""));
  const sources = new Set<string>();
  let chars = 0;
  for (const raw of entries) {
    const entry = tryParseHostEntry(raw);
    if (entry === null || (entry.ip && entry.host.includes(":"))) continue;
    const names = (host: string): boolean =>
      entry.wildcard ? host.endsWith(`.${entry.host}`) : host === entry.host;
    if (isLoopback(entry.host) || own.some(names)) continue;
    const port = entry.ports.length === 1 ? `:${entry.ports[0]}` : "";
    const host = entry.wildcard ? `*.${entry.host}` : entry.host;
    const fresh = SCHEMES.map((scheme) => `${scheme}://${host}${port}`).filter(
      (source) => SOURCE.test(source) && !sources.has(source),
    );
    const cost = fresh.reduce((sum, source) => sum + source.length + 1, 0);
    if (chars + cost > MAX_HOST_SOURCE_CHARS) break;
    chars += cost;
    for (const source of fresh) sources.add(source);
  }
  return [...sources];
}

/**

export function serviceCsp({ appOrigins, previewOrigin, hosts }: ServiceCspInput): string {
  const reach = [previewOrigin, ...hosts].join(" ");

    "sandbox allow-scripts allow-forms allow-downloads",

    `worker-src ${previewOrigin}`,
    "object-src 'none'",
    `form-action ${reach}`,

}

export interface BoxSlots {

  count(box: string): number;

/** A counter per box: the map holds only boxes with a live tunnel, so it is bounded by the boxes that exist. */
export function createBoxSlots(max: number): BoxSlots {
  const used = new Map<string, number>();
  return {
    take(box) {
      const now = used.get(box) ?? 0;
      if (now >= max) return null;
      used.set(box, now + 1);
      let released = false;
      return () => {
        if (released) return;
        released = true;
        const left = (used.get(box) ?? 1) - 1;
        if (left <= 0) used.delete(box);
        else used.set(box, left);
      };
    },

  };

export interface IdleWatch {
  /** Bytes moved: the idle wait starts again. */
  touch(): void;
  stop(): void;
}

/** One timer per connection, re-armed for the remainder when it fires early: a busy connection costs no timer per chunk. */
export function idleWatch(clock: Clock, ms: number, onIdle: () => void): IdleWatch {
  let last = clock.now();
  let timer: TimerHandle | undefined;
  let stopped = false;
  const arm = (delay: number): void => {
    timer = clock.setTimeout(() => {
      timer = undefined;
      if (stopped) return;
      const quiet = clock.now() - last;
      if (quiet >= ms) {
        stopped = true;
        onIdle();
      } else arm(ms - quiet);
    }, delay);
  };
  arm(ms);
  return {
    touch: () => void (last = clock.now()),
    stop() {
      stopped = true;
      if (timer !== undefined) clock.clearTimeout(timer);
      timer = undefined;
    },
  };
}

export type PreviewRefusal =
  "not_found" | "busy" | "too_large" | "box_stopped" | "upstream_failed" | "idle" | "dest_refused";

/**
 * `preview_refused`, at most once per reason and token a minute, with the count it stands for. The token is a hash
 * (`tokenRef`). Pairs are forgotten once their minute is over; while 1024 live pairs are held, a new pair shares the
 * reason's `t:*` line instead of evicting one.
 */
export function createRefusalLog(
  logger: Logger,
  clock: Clock,
): (reason: PreviewRefusal, token: string | null) => void {
  const windows = new Map<string, { at: number; suppressed: number }>();
  return (reason, token) => {
    const now = clock.now();
    if (windows.size >= PREVIEW_LIMITS.refusalKeys)
      for (const [key, window] of windows)
        if (now - window.at >= PREVIEW_LIMITS.refusalEveryMs) windows.delete(key);
    let ref = tokenRef(token);
    if (!windows.has(`${reason}:${ref}`) && windows.size >= PREVIEW_LIMITS.refusalKeys) ref = "t:*";
    const key = `${reason}:${ref}`;
    const window = windows.get(key);
    if (window !== undefined && now - window.at < PREVIEW_LIMITS.refusalEveryMs) {
      window.suppressed++;
      return;
    }
    windows.set(key, { at: now, suppressed: 0 });
    logger.warn("preview_refused", { reason, ref, suppressed: window?.suppressed ?? 0 });
  };
}

export interface OpenQueue {
  /**
   * Runs `open` once one of the box's `inFlight` places is free, in arrival order. Rejects `OpenBusy` at once when `waiting`
   * opens of the box already wait, and when its place has not come within `waitMs`; an aborted wait leaves the queue.
   */
  run<T>(box: string, open: () => Promise<T>, signal?: AbortSignal): Promise<T>;
  /** Opens of `box` in flight and waiting: the map holds only boxes with one of either. */
  size(box: string): { inFlight: number; waiting: number };
}

/**
 * Red team I3: a page's CSS, scripts and images arrive at once (a browser opens up to 6 connections), and every relayed request
 * needs a tunnel of its own. Two opens per box go to the guest at a time; the others wait their turn instead of failing. The
 * wait is bounded in count and in time and never evicts one already waiting (refuse when full).
 */
export function createOpenQueue(options: {
  readonly clock: Clock;
  readonly inFlight: number;
  readonly waiting: number;
  readonly waitMs: number;
}): OpenQueue {
  interface Waiter {
    readonly start: () => void;
  }
  const boxes = new Map<string, { running: number; queue: Waiter[] }>();
  const stateOf = (box: string) => {
    let state = boxes.get(box);
    if (state === undefined) {
      state = { running: 0, queue: [] };
      boxes.set(box, state);
    }
    return state;
  };
  const forget = (box: string): void => {
    const state = boxes.get(box);
    if (state !== undefined && state.running === 0 && state.queue.length === 0) boxes.delete(box);
  };
  const leave = (box: string, waiter: Waiter): boolean => {
    const state = boxes.get(box);
    const at = state?.queue.indexOf(waiter) ?? -1;
    if (state === undefined || at < 0) return false;
    state.queue.splice(at, 1);
    forget(box);
    return true;
  };
  const next = (box: string): void => {
    const state = boxes.get(box);
    if (state === undefined) return;
    state.running--;
    const waiter = state.queue.shift();
    if (waiter !== undefined) waiter.start();
    else forget(box);
  };
  return {
    run(box, open, signal) {
      if (signal?.aborted) return Promise.reject(new OpenBusy("aborted"));
      const state = stateOf(box);
      const go = <T>(
        resolve: (value: T) => void,
        reject: (error: unknown) => void,
        task: () => Promise<T>,
      ) => {
        state.running++;
        let settled = false;
        const done = () => {
          if (settled) return;
          settled = true;
          next(box);
        };
        task().then(
          (value) => {
            done();
            resolve(value);
          },
          (error: unknown) => {
            done();
            reject(error);
          },
        );
      };
      return new Promise((resolve, reject) => {
        if (state.running < options.inFlight && state.queue.length === 0) return go(resolve, reject, open);
        if (state.queue.length >= options.waiting) {
          forget(box);
          return reject(new OpenBusy("too many opens waiting"));
        }
        let timer: TimerHandle | undefined;
        const onAbort = () => {
          if (timer !== undefined) options.clock.clearTimeout(timer);
          if (leave(box, waiter)) reject(new OpenBusy("aborted"));
        };
        const waiter: Waiter = {
          start: () => {
            if (timer !== undefined) options.clock.clearTimeout(timer);
            signal?.removeEventListener("abort", onAbort);
            go(resolve, reject, open);
          },
        };
        timer = options.clock.setTimeout(() => {
          timer = undefined;
          signal?.removeEventListener("abort", onAbort);
          if (leave(box, waiter)) reject(new OpenBusy("waited too long"));
        }, options.waitMs);
        signal?.addEventListener("abort", onAbort, { once: true });
        state.queue.push(waiter);
      });
    },
    size: (box) => {
      const state = boxes.get(box);
      return { inFlight: state?.running ?? 0, waiting: state?.queue.length ?? 0 };
    },
  };
}

/** In memory only (spec §4): a daemon restart revokes every preview link. */
export function createPreviewTokens(clock: Clock): PreviewTokens {
  const entries = new Map<string, Entry>();
  const leases = new Map<string, string>();
  /** The newest token key of each fence; bounded by the artifact entries, dropped with them. */
  const fences = new Map<string, string>();

  const drop = (key: string): void => {
    const entry = entries.get(key);
    if (entry === undefined) return;
    entries.delete(key);
    if (entry.lease !== null) leases.delete(entry.lease);
    if (entry.grant.kind === "artifact") {
      const fence = fenceOf(entry.grant);
      if (fences.get(fence) === key) fences.delete(fence);
    }
  };
  const live = (key: string): Entry | null => {
    const entry = entries.get(key);
    if (entry === undefined) return null;
    if (clock.now() < entry.until) return entry;
    drop(key);
    return null;
  };
  const sweep = (): void => {
    for (const key of [...entries.keys()]) live(key);
  };
  const count = (kind: PreviewGrant["kind"], ownerId?: string): number => {
    let n = 0;
    for (const { grant } of entries.values())
      if (grant.kind === kind && (ownerId === undefined || grant.ownerId === ownerId)) n++;
    return n;
  };
  const roomFor = (kind: PreviewGrant["kind"], ownerId: string, perOwner: number, total: number): void => {
    sweep();
    if (count(kind, ownerId) >= perOwner || count(kind) >= total) throw new PapError("limit_reached");
  };
  const revokeWhere = (match: (grant: PreviewGrant) => boolean): number => {
    let n = 0;
    for (const [key, entry] of [...entries])
      if (match(entry.grant)) {
        drop(key);
        n++;
      }
    return n;
  };
  const ownLease = (ownerId: string, lease: string): { key: string; entry: Entry } | null => {
    const key = leases.get(lease);
    const entry = key === undefined ? null : live(key);
    return key === undefined || entry === null || entry.grant.ownerId !== ownerId ? null : { key, entry };
  };

  return {
    mintService(grant) {
      const { servicePerOwner, serviceTotal, leaseMs } = PREVIEW_TOKEN_LIMITS;
      roomFor("service", grant.ownerId, servicePerOwner, serviceTotal);
      const token = newToken();
      const lease = randomBytes(16).toString("hex");
      const until = clock.now() + leaseMs;
      const key = keyOf(token);
      entries.set(key, {
        grant: { kind: "service", ...grant, sources: [...grant.sources] },
        until,
        lease,
        token: null,
      });
      leases.set(lease, key);
      return { token, lease, until };
    },
    renew(ownerId, lease) {
      const found = ownLease(ownerId, lease);
      if (found === null) return null;
      found.entry.until = clock.now() + PREVIEW_TOKEN_LIMITS.leaseMs;
      return found.entry.until;
    },
    close(ownerId, lease) {
      const found = ownLease(ownerId, lease);
      if (found === null) return false;
      drop(found.key);
      return true;
    },
    mintArtifact(grant) {
      const { artifactPerOwner, artifactTotal, artifactMs, artifactBytes, artifactReuseMs } =
        PREVIEW_TOKEN_LIMITS;
      if (Buffer.byteLength(grant.html, "utf8") > artifactBytes) throw new PapError("payload_too_large");
      const fence = fenceOf(grant);
      const known = fences.get(fence);
      const reused = known === undefined ? null : live(known);
      if (reused?.token != null && reused.until - clock.now() >= artifactReuseMs)
        return { token: reused.token, until: reused.until };
      roomFor("artifact", grant.ownerId, artifactPerOwner, artifactTotal);
      const token = newToken();
      const until = clock.now() + artifactMs;
      const key = keyOf(token);
      entries.set(key, { grant: { kind: "artifact", ...grant }, until, lease: null, token });
      fences.set(fence, key);
      return { token, until };
    },
    resolve(kind, token) {
      const entry = live(keyOf(token));
      return entry !== null && entry.grant.kind === kind ? entry.grant : null;
    },
    revokeService: (serviceId) =>
      revokeWhere((grant) => grant.kind === "service" && grant.serviceId === serviceId),
    revokeBox: (box) => revokeWhere((grant) => grant.kind === "service" && boxKey(grant.box) === boxKey(box)),
    revokeOwner: (ownerId) => revokeWhere((grant) => grant.ownerId === ownerId),
    sweep,
  };
}

import type { MiddlewareHandler } from "hono";
import { isHookRequest } from "./hook-path.ts";
import { isReserved } from "./reserved.ts";

/** Told of every request refused for its `Sec-Fetch-Site`: the composition root logs it, rate-limited (`fetch_site_refused`). */
export type FetchSiteRefused = (via: "http" | "ws", site: string) => void;

/** SameSite ignores ports, so the preview origin is same-site with pap: both of these are refused (spec §4). */
const REFUSED: ReadonlySet<string> = new Set(["same-site", "cross-site"]);
/** GitHub sends the browser back to these after the App manifest and the install (`auth.md`, "GitHub callbacks"). */
const GITHUB_CALLBACKS: ReadonlySet<string> = new Set(["/github/app/created", "/github/app/authorized"]);

export interface FetchMeta {
  readonly method: string;
  readonly path: string;
  readonly site: string | undefined;
  readonly mode: string | undefined;
  readonly dest: string | undefined;
}

/**
 * Whether a request is refused for where it comes from. A request without `Sec-Fetch-Site` (a browser before Safari 16.4,
 * a program) keeps today's checks: the Origin guard, SameSite=Strict cookies, the WebSocket Origin rule. The exceptions:
 * a webhook, the two GitHub callbacks, and a top-level navigation to the app shell (a link or a typed address opens pap;
 * every route, the WebSocket and every embed stay refused).
 */
export function fetchSiteRefused(meta: FetchMeta): boolean {
  if (meta.site === undefined || !REFUSED.has(meta.site.toLowerCase())) return false;
  if (isHookRequest(meta.method, meta.path)) return false;
  if (meta.method === "GET" && GITHUB_CALLBACKS.has(meta.path)) return false;
  const navigation =
    (meta.method === "GET" || meta.method === "HEAD") &&
    meta.mode === "navigate" &&
    (meta.dest === undefined || meta.dest === "document");
  return !(navigation && !isReserved(meta.path));
}

/** Every route of the app: 403 `forbidden` for a refused site, before the Origin guard and any route runs. */
export function fetchSiteGuard(onRefused?: FetchSiteRefused): MiddlewareHandler {
  return async (c, next) => {
    const site = c.req.header("sec-fetch-site");
    const meta = {
      method: c.req.method,
      path: c.req.path,
      site,
      mode: c.req.header("sec-fetch-mode"),
      dest: c.req.header("sec-fetch-dest"),
    };
    if (fetchSiteRefused(meta)) {
      onRefused?.("http", site ?? "");
      return c.json({ error: { code: "forbidden" } }, 403);
    }
    await next();
  };
}

- **UX2-R8. The navigation exception is a document navigation to a non-reserved path, by `GET` or `HEAD`.** An iframe or embed navigation (`Sec-Fetch-Dest: iframe`) is refused; `isReserved` decodes the path once, as the static fallback does. import { z } from "zod";

/** Unacknowledged bytes one side of a tunnel may have in flight before it stops reading (UX-2 §6: the terminals' rule). */
export const TUNNEL_WINDOW_BYTES = 1024 * 1024;
/** Raw bytes in one `tunnel_data` frame. */
export const TUNNEL_FRAME_BYTES = 64 * 1024;
const TUNNEL_FRAME_B64 = Math.ceil(TUNNEL_FRAME_BYTES / 3) * 4;

const Base64 = /^(?:[A-Za-z0-9+/]{4})*(?:[A-Za-z0-9+/]{2}==|[A-Za-z0-9+/]{3}=)?$/;
const rawBytes = (b64: string): number =>
  (b64.length / 4) * 3 - (b64.endsWith("==") ? 2 : b64.endsWith("=") ? 1 : 0);

/**
 * Both directions of a tunnel connection after its hello. `tunnel_data` carries 1 to 64 KiB; `tunnel_ack` the cumulative
 * bytes the other side has taken (never more than it was sent: the receiver closes the tunnel on such an ack); `tunnel_end`
 * says that side will send no more (a half-close). The gateway's transport frames (`ping`, `pong`) are not tunnel frames:
 * every reader answers a `ping` with a `pong` before it parses a `TunnelFrame` (the gateway closes a connection after three
 * unanswered pings, 45 s). Any other shape closes the tunnel.
 */
export const TunnelFrame = z.discriminatedUnion("type", [
  z
    .object({
      type: z.literal("tunnel_data"),
      data: z
        .string()
        .min(4)
        .max(TUNNEL_FRAME_B64)
        .regex(Base64)
        .refine((b64) => rawBytes(b64) <= TUNNEL_FRAME_BYTES, "at most 64 KiB raw"),
    })
    .strict(),
  z
    .object({ type: z.literal("tunnel_ack"), bytes: z.number().int().min(0).max(Number.MAX_SAFE_INTEGER) })
    .strict(),
  z.object({ type: z.literal("tunnel_end") }).strict(),
]);
export type TunnelFrame = z.infer<typeof TunnelFrame>;

/** The ppid of a `/proc/<pid>/stat` line: the comm field is in parentheses and may itself hold spaces and parentheses. */
export function ppidOf(stat: string): number | null {
  const close = stat.lastIndexOf(")");
  if (close < 0) return null;
  const ppid = Number(stat.slice(close + 2).split(" ")[1]);
  return Number.isSafeInteger(ppid) && ppid >= 0 ? ppid : null;
}

/** Field 22 of a `/proc/<pid>/stat` line (the start time in clock ticks since boot), after the parenthesised comm. */
export function startTimeOf(stat: string): string | null {
  const close = stat.lastIndexOf(")");
  if (close < 0) return null;
  const start = stat.slice(close + 2).split(" ")[19];
  return start !== undefined && /^\d+$/.test(start) ? start : null;
}

/** The root and every descendant, from one pass over `/proc`. */
export function treeOf(root: number, proc: ProcReader): number[] {
  const children = new Map<number, number[]>();
  for (const pid of proc.pids()) {
    const stat = proc.stat(pid);
    const ppid = stat === null ? null : ppidOf(stat);
    if (ppid === null || pid === ppid) continue;
    children.set(ppid, [...(children.get(ppid) ?? []), pid]);
  }
  const tree: number[] = [];
  const seen = new Set<number>();
  for (const queue = [root]; queue.length > 0;) {
    const pid = queue.shift() as number;
    if (seen.has(pid)) continue;
    seen.add(pid);
    tree.push(pid);
    queue.push(...(children.get(pid) ?? []));
  }
  return tree;
}

interface Listener {
  readonly inode: string;
  /** How the guest can dial it: through IPv4 loopback, IPv6 loopback, or not at all (bound to another address). */
  readonly via: "v4" | "v6" | null;
}

// `/proc/net/tcp*` print each 32-bit word of an address in host order: little-endian on x86_64, pap's only VM architecture.
const V4_DIAL: ReadonlySet<string> = new Set(["00000000", "0100007F"]);
const V6_ANY = "00000000000000000000000000000000";
const V6_LOOP = "00000000000000000000000001000000";
const V6_MAPPED_V4_LOOP = "0000000000000000FFFF00000100007F";
const LISTEN = "0A";

/** The LISTEN sockets of one table on `port`. */
export function listenersOn(table: string, port: number, family: "v4" | "v6"): Listener[] {
  const found: Listener[] = [];
  for (const line of table.split("\n").slice(1)) {
    const fields = line.trim().split(/\s+/);
    const local = fields[1];
    const inode = fields[9];
    if (fields[3] !== LISTEN || local === undefined || inode === undefined || !/^\d+$/.test(inode)) continue;
    const colon = local.lastIndexOf(":");
    if (colon < 0 || Number.parseInt(local.slice(colon + 1), 16) !== port) continue;
    const address = local.slice(0, colon).toUpperCase();
    const via =
      family === "v4"
        ? V4_DIAL.has(address)
          ? "v4"
          : null
        : address === V6_MAPPED_V4_LOOP
          ? "v4"
          : address === V6_ANY || address === V6_LOOP
            ? "v6"
            : null;
    found.push({ inode, via });
  }
  return found;
}

const SOCKET_LINK = /^socket:\[(\d+)\]$/;

/**
 * Spec §5 (controller's call): a service is `running` only when every socket listening on its port, in its own network
 * namespace, belongs to its own process tree (the bwrap it was started with and every descendant). A listener of anything
 * else in the VM (Pi, an MCP server, another service) on that port is `port_not_owned`; no listener yet, or one the guest
 * cannot dial (bound to another address), is `not_listening`. The tunnel checks again before each connection.
 */
export function checkOwnership(root: number, port: number, from: NetnsFrom, proc: ProcReader): Ownership {
  if (proc.stat(root) === null) return { owned: false, reason: "gone" };
  const tree = treeOf(root, proc);
  const nsPid = from === "root" ? root : tree.find((pid) => pid !== root);
  if (nsPid === undefined) return { owned: false, reason: "not_listening" };
  const tables = proc.tcpTables(nsPid);
  if (tables === null) return { owned: false, reason: "gone" };
  const listeners = [...listenersOn(tables.v4, port, "v4"), ...listenersOn(tables.v6, port, "v6")];
  if (listeners.length === 0) return { owned: false, reason: "not_listening" };
  const inodes = new Set<string>();
  for (const pid of tree)
    for (const link of proc.fdLinks(pid)) {
      const inode = SOCKET_LINK.exec(link)?.[1];
      if (inode !== undefined) inodes.add(inode);
    }
  if (!listeners.every((listener) => inodes.has(listener.inode)))
    return { owned: false, reason: "port_not_owned" };
  const stat = proc.stat(nsPid);
  const nsStart = stat === null ? null : startTimeOf(stat);
  if (nsStart === null) return { owned: false, reason: "gone" };
  if (listeners.some((listener) => listener.via === "v4"))
    return { owned: true, host: "127.0.0.1", nsPid, nsStart };
  if (listeners.some((listener) => listener.via === "v6"))
    return { owned: true, host: "::1", nsPid, nsStart };
  return { owned: false, reason: "not_listening" };
}

const read = (path: string): string | null => {
  try {
    return readFileSync(path, "utf8");
  } catch {
    return null;
  }
};

/** The guest's `/proc` (guest root reads every process of the VM, sandboxed ones included). */
export function procReader(root = "/proc"): ProcReader {
  return {
    pids: () => {
      try {
        return readdirSync(root)
          .filter((name) => /^\d+$/.test(name))
          .map(Number);
      } catch {
        return [];
      }
    },
    stat: (pid) => read(`${root}/${pid}/stat`),
    fdLinks: (pid) => {
      try {
        return readdirSync(`${root}/${pid}/fd`).flatMap((fd) => {
          try {
            return [readlinkSync(`${root}/${pid}/fd/${fd}`)];
          } catch {
            return [];
          }
        });
      } catch {
        return [];
      }
    },
    tcpTables: (pid) => {
      const v4 = read(`${root}/${pid}/net/tcp`);
      const v6 = read(`${root}/${pid}/net/tcp6`);
      return v4 === null && v6 === null ? null : { v4: v4 ?? "", v6: v6 ?? "" };
    },
  };
}

  `--net=/proc/self/fd/${NETNS_FD}`,
  "--",
  process.execPath,
  ...process.execArgv.filter((arg) => arg.startsWith("--conditions=")),
  helperEntry(),
];

/**
 * A service without network has its own network namespace (bwrap `--unshare-net`): nothing in the VM reaches its loopback.
 * One helper per such service is started inside that namespace only; it opens each connection there and passes the socket
 * back (`process.send` with a handle), so the bytes flow on the guest's own socket and the service's namespace gains no
 * route, no interface and no listener (spec §5: entered, never widened). The helper sits outside bwrap, in the guest's pid
 * namespace: the service can neither see nor signal it.
 */
export function startNsDialer(deps: NsDialerDeps): NsDialer {
  const [file = NSENTER, ...args] = (deps.command ?? nsenterCommand)();
  const child: ChildProcess = deps.spawn(file, args, {
    cwd: "/",
    env: { PATH: "/usr/bin:/bin" },
    stdio: ["ignore", "ignore", "ignore", "ipc", deps.nsFd],
  });
  const pending = new Map<
    number,
    { resolve: (socket: net.Socket) => void; reject: (error: Error) => void; timer: unknown }
  >();
  let next = 0;
  let over = false;
  const settle = (id: number, outcome: net.Socket | Error): void => {
    const waiting = pending.get(id);
    if (waiting === undefined) {
      if (outcome instanceof net.Socket) outcome.destroy();
      return;
    }
    pending.delete(id);
    deps.clock.clearTimeout(waiting.timer);
    if (outcome instanceof net.Socket) waiting.resolve(outcome);
    else waiting.reject(outcome);
  };
  const failAll = (why: string): void => {
    over = true;
    for (const id of [...pending.keys()]) settle(id, new Error(why));
  };
  child.on("message", (raw: unknown, handle: unknown) => {
    const { id, ok } = (typeof raw === "object" && raw !== null ? raw : {}) as { id?: unknown; ok?: unknown };
    if (typeof id !== "number") {
      if (handle instanceof net.Socket) handle.destroy();
      return;
    }
    settle(
      id,
      ok === true && handle instanceof net.Socket ? handle : new Error("the service refused the connection"),
    );
  });
  child.on("error", () => {
    deps.log("the namespace helper could not start");
    failAll("the namespace helper failed");
  });
  child.on("exit", () => failAll("the namespace helper exited"));
  return {
    dial(host, port) {
      if (over || !child.connected) return Promise.reject(new Error("the namespace helper is gone"));
      if (pending.size >= NS_DIALS_IN_FLIGHT) return Promise.reject(new Error("too many dials"));
      const id = ++next;
      return new Promise((resolve, reject) => {
        const timer = deps.clock.setTimeout(() => settle(id, new Error("the dial timed out")), NS_DIAL_MS);
        pending.set(id, { resolve, reject, timer });
        child.send({ id, host, port }, (error) => {
          if (error) settle(id, new Error("the namespace helper is gone"));
        });
      });
    },
    close() {
      failAll("closed");
      if (child.exitCode === null && child.signalCode === null) child.kill("SIGKILL");
    },
  };
}

/**
 * The namespace helper's own program (spec §5): the guest starts it with `nsenter --net=/proc/<pid>/ns/net` inside a
 * service's network namespace and nothing else, so it shares that loopback and no other namespace. For each request it
 * connects to the service's port on loopback and hands the connected socket back over the IPC channel, then forgets it.
 * It reads no byte of the connection (HTTP speaks first from the client). Anything that is not a well-formed request is ignored.
 */
const HOSTS: ReadonlySet<string> = new Set(["127.0.0.1", "::1"]);

process.on("message", (raw: unknown) => {
  if (typeof raw !== "object" || raw === null) return;
  const { id, host, port } = raw as { id?: unknown; host?: unknown; port?: unknown };
  if (typeof id !== "number" || !Number.isSafeInteger(id) || id < 1) return;
  if (typeof host !== "string" || !HOSTS.has(host)) return;
  if (typeof port !== "number" || !Number.isInteger(port) || port < 1024 || port > 65_535) return;
  const socket = net.connect({ host, port });
  socket.once("connect", () => process.send?.({ id, ok: true }, socket));
  socket.once("error", () => {
    socket.destroy();
    process.send?.({ id, ok: false });
  });
});
// The guest is gone or closed the channel: the helper has nothing left to do.
process.on("disconnect", () => process.exit(0));

import type net from "node:net";
import {
  AGENT_VM_MAX_FRAME_BYTES,
  createFrameDecoder,
  encodeSocketFrame,
  TUNNEL_FRAME_BYTES,
  TUNNEL_WINDOW_BYTES,
  TunnelFrame,
} from "@pap/contracts/pi-host";
import { errorClass } from "../../bounded.ts";

/** Open tunnels one guest holds at once; the daemon's 32 per box is the real bound, the next open is refused. */
export const TUNNELS_PER_GUEST = 64;
/** A paused service socket resumes when the unacknowledged data is down to this much. */
const RESUME_BYTES = TUNNEL_WINDOW_BYTES / 2;
const PONG = encodeSocketFrame({ type: "pong" });
/** The one sentence the daemon gets for any open that fails before the side connection (never an address or an errno). */
export const TUNNEL_REFUSAL = "the service is not running or does not own its port";

export interface TunnelHostDeps {
  /** A connected socket to a running service's port, ownership checked again (spec §5); throws otherwise. */
  readonly services: { connectTo(serviceId: string): Promise<net.Socket> };
  /** The side connection of `slot`, its `tunnel` hello written (`dialSide(…, { role: "tunnel", slot })`). */
  side(slot: string): Promise<net.Socket>;
  /** Tells the daemon the slot could not open (an `exited` report with the slot and `TUNNEL_REFUSAL`). */
  refuse(slot: string, why: string): void;
  log(line: string): void;
}

export interface TunnelHost {
  open(command: { readonly slot: string; readonly service: string }): void;
  closeAll(): void;
  /** Open tunnels and tunnels being opened: the only entries this host keeps (red team I6). */
  size(): number;
}

/**
 * The guest's tunnels (UX-2 §6, UX2-R23). `tunnel_open` connects to the service first, then dials the side connection with
 * its hello, then splices: service bytes go out as `tunnel_data` of at most 64 KiB and stop while 1 MiB is unacknowledged
 * (resumed at half; the rest of a chunk waits, so the daemon never sees more than the window plus one frame); incoming data is
 * written to the service and acknowledged once written. The gateway's `ping` is answered with `pong` before any tunnel frame is
 * parsed (red team I4: the gateway closes a connection after three unanswered pings, 45 s). Red team I6: only open tunnels are
 * kept, and an entry goes when its tunnel ends; replaying a slot is the daemon's to refuse (it deleted the slot).
 */
export function createTunnelHost(deps: TunnelHostDeps): TunnelHost {
  const live = new Map<string, () => void>();

  function splice(slot: string, service: net.Socket, side: net.Socket, end: () => void): void {
    let sent = 0;
    let acked = 0;
    let written = 0;
    let paused = false;
    let held: Buffer | null = null;
    /** The service will send no more (its `end`, or its socket closed); `tunnel_end` goes once what it sent is out. */
    let finished = false;
    let endSent = false;
    let serviceClosed = false;
    const send = (frame: TunnelFrame): void => {
      if (!side.destroyed) side.write(encodeSocketFrame(frame));
    };
    const pump = (): void => {
      while (held !== null && sent - acked < TUNNEL_WINDOW_BYTES) {
        const part = held.subarray(0, TUNNEL_FRAME_BYTES);
        held = part.length < held.length ? held.subarray(part.length) : null;
        send({ type: "tunnel_data", data: part.toString("base64") });
        sent += part.length;
      }
      if (held === null && finished && !endSent) {
        endSent = true;
        send({ type: "tunnel_end" });
      }
      if (endSent && serviceClosed && side.writable) side.end();
      if (finished) return;
      const lag = sent - acked;
      const want = held === null && (paused ? lag <= RESUME_BYTES : lag < TUNNEL_WINDOW_BYTES);
      if (want === !paused) return;
      paused = !want;
      if (paused) service.pause();
      else service.resume();
    };
    const decoder = createFrameDecoder({
      maxBytes: () => AGENT_VM_MAX_FRAME_BYTES,
      onFrame: (raw) => {
        // Transport first (red team I4): the gateway's ping is no tunnel frame, and an unanswered one closes the connection.
        if ((raw as { type?: unknown } | null)?.type === "ping") {
          if (!side.destroyed) side.write(PONG);
          return;
        }
        const parsed = TunnelFrame.safeParse(raw);
        if (!parsed.success) {
          deps.log(`slot ${slot} tunnel frame refused`);
          return end();
        }
        const frame = parsed.data;
        if (frame.type === "tunnel_data") {
          const bytes = Buffer.from(frame.data, "base64");
          service.write(bytes, () => {
            written += bytes.length;
            send({ type: "tunnel_ack", bytes: written });
          });
        } else if (frame.type === "tunnel_ack") {
          if (frame.bytes > sent) {
            deps.log(`slot ${slot} acknowledged more than it was sent`);
            return end();
          }
          if (frame.bytes > acked) acked = frame.bytes;
          pump();
        } else service.end();
      },
      onError: (error) => {
        deps.log(`slot ${slot} tunnel frame refused (${error})`);
        end();
      },
    });
    side.on("data", (chunk: Buffer) => decoder.push(chunk));
    side.on("close", () => {
      decoder.stop();
      end();
    });
    side.on("error", (error) => deps.log(`slot ${slot} tunnel socket error: ${errorClass(error)}`));
    service.on("data", (chunk: Buffer) => {
      held = held === null ? chunk : Buffer.concat([held, chunk]);
      pump();
    });
    service.on("end", () => {
      finished = true;
      pump();
    });
    service.on("close", () => {
      finished = true;
      serviceClosed = true;
      pump();
    });
    service.on("error", (error) => deps.log(`slot ${slot} service socket error: ${errorClass(error)}`));
  }

  return {
    open(command) {
      const { slot } = command;
      if (live.has(slot)) return deps.log(`ignored tunnel_open of slot ${slot}: it is open`);
      if (live.size >= TUNNELS_PER_GUEST) return deps.refuse(slot, TUNNEL_REFUSAL);
      let ended = false;
      let service: net.Socket | undefined;
      let side: net.Socket | undefined;
      const end = (): void => {
        if (ended) return;
        ended = true;
        live.delete(slot);
        service?.destroy();
        side?.destroy();
      };
      live.set(slot, end);
      void (async () => {
        try {
          service = await deps.services.connectTo(command.service);
        } catch {
          if (ended) return;
          end();
          return deps.refuse(slot, TUNNEL_REFUSAL);
        }
        if (ended) return void service.destroy();
        try {
          side = await deps.side(slot);
        } catch (error) {
          deps.log(`slot ${slot} side connection failed: ${errorClass(error)}`);
          return end();
        }
        if (ended) return void side.destroy();
        splice(slot, service, side, end);
      })();
    },
    closeAll() {
      for (const end of [...live.values()]) end();
    },
    size: () => live.size,
  };
}

**Rulings:**
- **UX2-R22 (rewritten, red team M3, M8). The namespace entry: `nsenter --net` on an inherited descriptor, plus socket hand-off.** One helper per no-network service, started lazily at the readiness probe (T5 R17) and kept until the service stops. The guest opens the namespace and checks the pid's start time (`openNetns`, UX2-R62), passes the descriptor as the helper's fd 4, runs `nsenter --net=/proc/self/fd/4 -- node <helper>` and closes its own copy. The service's own pid namespace and seccomp filter keep it from touching the helper. `util-linux` is in `BASE_PACKAGES` from this task on (UX2-R63), no longer a fallback. Cost if wrong: one node process (about 40 MB) per no-network service, 4 at most.
- **UX2-R23 (rewritten, red team I4, I6). Tunnel flow.** Order: `connectTo(serviceId)` (ownership checked again, then a direct connect for a networked service or the helper's socket), then `side(slot)`; a failure before the side connection is `refuse(slot, TUNNEL_REFUSAL)` (one fixed sentence, never an errno or an address). The gateway's `ping` is answered before any `TunnelFrame` parse (UX2-R60). Out: service bytes go as `tunnel_data` of at most 64 KiB while less than 1 MiB is unacknowledged; the rest of a chunk is held and the service socket paused, resumed at half, so the daemon never sees more than the window plus one frame (the limit of UX2-R65). In: `tunnel_data` is written to the service and acknowledged cumulatively once written (`write` callback). `tunnel_end` goes out only after every held byte; the daemon's `tunnel_end` half-closes the service; a malformed frame, an ack beyond what was sent, or the side closing ends both; the service closing ends the side once its data and `tunnel_end` are out. At most 64 open tunnels per guest (`TUNNELS_PER_GUEST`; the daemon's 32 per box is the real bound).
- **UX2-R60 (red team I4). Transport frames first.** `gateway.ts` arms its 15 s ping for every accepted connection, tunnels included, and closes one after three unanswered pings. `tunnels.ts` answers `ping` before it parses a `TunnelFrame`, as `pty.ts` does (line 172), and `tunnel-frames.ts` says transport frames are not tunnel frames. Without it every tunnel died at 45 s (WebSockets, live reload, slow downloads). Cost if wrong: none.
- **UX2-R61 (red team I6). The guest keeps open tunnels only.** `pty.ts`'s `used` set grows forever; copied into tunnels it would hold one entry per relayed request (about 864 000 a day for a page polling ten times a second). `tunnels.ts` keeps a map of tunnels being opened or open, each entry removed when its tunnel ends; replaying a slot is the daemon's to refuse (it deleted the slot, UX2-R64). Cost if wrong: none.
- **UX2-R62 (red team M8). The namespace is held by a descriptor before it is used.** `openNetns({pid, start})` opens `/proc/<pid>/ns/net` first, then reads the pid's start time again: equal to `Ownership.nsStart`, the descriptor names that very process's namespace and keeps it alive as long as the helper runs; otherwise nothing is entered. Cost if wrong: none.
- **UX2-R63 (red team M3). `util-linux` in the base image now.** `BASE_PACKAGES` gains `util-linux` (Essential in Debian, so usually present: the plan fix found `/usr/bin/nsenter` in `node:24-bookworm-slim`; the pinned `node:24.14.1-trixie-slim` could not be checked offline) and the base salt moves to `pap-base-3`, so the recipe change and the tag move together. import { randomBytes } from "node:crypto";
import { type GuestCommand, type Hello, PapError, TunnelFrame } from "@pap/contracts";
import type { BoxTunnelChannel } from "../../kernel/boxes.ts";
import type { Clock, TimerHandle } from "../../kernel/clock.ts";
import type { Logger } from "../../kernel/logger.ts";
import type { Wire } from "./vm-worker.ts";

/** From `tunnel_open` to the tunnel hello: the guest's own connect timeout is 10 s. */
export const TUNNEL_OPEN_MS = 15_000;

/** What the gateway does with a tunnel connection that passed its hello. */
export interface TunnelConnection {
  frame(raw: unknown): void;
  closed(): void;
}

export type TunnelRefusal = "slot" | "duplicate";

export interface GuestTunnels {
  /** Asks the guest for a tunnel to the service; resolves once its `tunnel` hello was accepted. */
  open(serviceId: string): Promise<BoxTunnelChannel>;
  accept(hello: Extract<Hello, { role: "tunnel" }>, wire: Wire): TunnelConnection | TunnelRefusal;
  /** The guest reported `exited` for `slot` before any hello: the open fails `not_found`. False when the slot is not a tunnel's. */
  refused(slot: string): boolean;
  /** The guest's connection closed: every tunnel of the launch ends, every open fails `box_stopped`. */
  closed(): void;
  /** Slot entries held: asked ones and open tunnels only (red team I6). */
  size(): number;
}

interface Slot {
  /** `asked`: `tunnel_open` went out. `open`: the hello came; a second hello is `duplicate`. */
  state: "asked" | "open";
  readonly resolve: (channel: BoxTunnelChannel) => void;
  readonly reject: (error: Error) => void;
  timer: TimerHandle | undefined;
  end?: () => void;
}

/**
 * The daemon's half of the tunnels of one guest link (UX-2 §6), the shape of `guest-ptys.ts` with one difference (red team
 * I6): a tunnel opens once per relayed request, so a slot entry is deleted as soon as it is given up (timeout, refusal, the
 * link gone) or its tunnel closes. A hello for a deleted slot is refused `slot`, as one for a slot never asked.
 */
export function createGuestTunnels(deps: {
  clock: Clock;
  logger: Logger;
  box: string;
  wire: Wire;
}): GuestTunnels {
  const { clock, logger, box, wire } = deps;
  const slots = new Map<string, Slot>();
  let isClosed = false;

  const giveUp = (slot: string, entry: Slot, error: Error): void => {
    if (entry.state !== "asked") return;
    slots.delete(slot);
    if (entry.timer) clock.clearTimeout(entry.timer);
    entry.timer = undefined;
    entry.reject(error);
  };

  function channelOf(
    slot: string,
    connection: Wire,
  ): { channel: BoxTunnelChannel; connection: TunnelConnection } {
    let listener: ((frame: TunnelFrame) => void) | undefined;
    const queued: TunnelFrame[] = [];
    let ended = false;
    let markClosed: () => void = () => {};
    const closed = new Promise<void>((resolve) => {
      markClosed = resolve;
    });
    const end = (): void => {
      if (ended) return;
      ended = true;
      slots.delete(slot);
      markClosed();
    };
    const channel: BoxTunnelChannel = {
      send: (frame) => !ended && connection.send(frame),
      onFrame(next) {
        listener = next;
        for (const frame of queued.splice(0)) next(frame);
      },
      closed,
      close: () => connection.close(),
    };
    return {
      channel,
      connection: {
        frame(raw) {
          const frame = TunnelFrame.safeParse(raw);
          if (!frame.success) {
            // Transport frames never reach here (the gateway answers them): anything else ends the tunnel, never its content logged.
            logger.warn("agent_gateway_tunnel_bad_frame", { box });
            connection.close();
            return;
          }
          if (listener) listener(frame.data);
          else queued.push(frame.data);
        },
        closed: end,
      },
    };
  }

  return {
    open(serviceId) {
      if (isClosed) return Promise.reject(new PapError("box_stopped"));
      const slot = randomBytes(16).toString("hex");
      return new Promise<BoxTunnelChannel>((resolve, reject) => {
        const entry: Slot = { state: "asked", resolve, reject, timer: undefined };
        entry.timer = clock.setTimeout(() => {
          logger.warn("agent_gateway_tunnel_timeout", { box });
          giveUp(slot, entry, new PapError("timeout"));
        }, TUNNEL_OPEN_MS);
        slots.set(slot, entry);
        const command: GuestCommand = { type: "tunnel_open", slot, service: serviceId };
        if (!wire.send(command)) giveUp(slot, entry, new PapError("box_stopped"));
      });
    },
    accept(hello, tunnelWire) {
      const entry = slots.get(hello.slot);
      if (entry === undefined) return "slot";
      if (entry.state !== "asked") return "duplicate";
      entry.state = "open";
      if (entry.timer) clock.clearTimeout(entry.timer);
      entry.timer = undefined;
      const { channel, connection } = channelOf(hello.slot, tunnelWire);
      entry.end = () => {
        connection.closed();
        tunnelWire.close();
      };
      entry.resolve(channel);
      return connection;
    },
    refused(slot) {
      const entry = slots.get(slot);
      if (entry === undefined) return false;
      giveUp(slot, entry, new PapError("not_found"));
      return true;
    },
    closed() {
      isClosed = true;
      for (const [slot, entry] of [...slots]) {
        giveUp(slot, entry, new PapError("box_stopped"));
        entry.end?.();
      }
    },
    size: () => slots.size,
  };
}

import type { BoxTunnelChannel } from "../../boxes.ts";

/** A guest may have this much unacknowledged data in flight: the window plus the one frame it may send while it fills. */
export const TUNNEL_RECEIVE_LIMIT = TUNNEL_WINDOW_BYTES + TUNNEL_FRAME_BYTES;

export class TunnelWindowBroken extends Error {
  override name = "TunnelWindowBroken";
}

/**
 * The stream the listener's `http.request({ createConnection })` and the WebSocket splice read and write (UX2-R25).
 * Out: a write is cut into frames of at most 64 KiB, and the rest of it waits, callback held, while 1 MiB is unacknowledged.
 * In: data is pushed and acknowledged cumulatively, except while `push` refuses (acks resume on `_read`). Red team I5: the
 * receiving side enforces the window, so a guest that ignores missing acks is cut (`TunnelWindowBroken`) once it has more
 * than `TUNNEL_RECEIVE_LIMIT` unacknowledged, before anything past it is buffered; an ack beyond what was sent is cut too.
 * The channel closing destroys the socket: at once mid-answer, after its buffered data was read once `tunnel_end` came.
 */
export function tunnelSocket(channel: BoxTunnelChannel): Duplex {
  let sent = 0;
  let acked = 0;
  let received = 0;
  let ackedOut = 0;
  let held: { chunk: Buffer; done: (error?: Error | null) => void } | null = null;
  let remoteEnded = false;

  const pump = (): void => {
    while (held !== null && sent - acked < TUNNEL_WINDOW_BYTES) {
      const part = held.chunk.subarray(0, TUNNEL_FRAME_BYTES);
      if (!channel.send({ type: "tunnel_data", data: part.toString("base64") })) {
        const { done } = held;
        held = null;
        return done(new Error("the tunnel is closed"));
      }
      sent += part.length;
      if (part.length < held.chunk.length) held = { ...held, chunk: held.chunk.subarray(part.length) };
      else {
        const { done } = held;
        held = null;
        done();
      }
    }
  };
  const ack = (): void => {
    if (received === ackedOut) return;
    ackedOut = received;
    channel.send({ type: "tunnel_ack", bytes: ackedOut });
  };

  const socket = new Duplex({
    write(chunk: Buffer, _encoding, done) {
      if (chunk.length === 0) return done();
      held = { chunk, done };
      pump();
    },
    final(done) {
      channel.send({ type: "tunnel_end" });
      done();
    },
    read() {
      ack();
    },
    destroy(error, done) {
      if (held !== null) {
        const pending = held.done;
        held = null;
        pending(error ?? new Error("the tunnel is closed"));
      }
      channel.close();
      done(error);
    },
  });

  channel.onFrame((frame) => {
    if (socket.destroyed) return;
    if (frame.type === "tunnel_ack") {
      if (frame.bytes > sent)
        return void socket.destroy(new TunnelWindowBroken("an ack beyond what was sent"));
      if (frame.bytes > acked) acked = frame.bytes;
      pump();
    } else if (frame.type === "tunnel_data") {
      const bytes = Buffer.from(frame.data, "base64");
      received += bytes.length;
      if (received - ackedOut > TUNNEL_RECEIVE_LIMIT)
        return void socket.destroy(new TunnelWindowBroken("the guest sent past its window"));
      if (socket.push(bytes)) ack();
    } else {
      remoteEnded = true;
      socket.push(null);
    }
  });
  // The guest ended the connection: after its `tunnel_end` the socket goes once what it sent was read; before it, at once.
  void channel.closed.then(() => {
    if (socket.destroyed) return;
    if (!remoteEnded || socket.readableEnded) socket.destroy();
    else socket.once("end", () => socket.destroy());
  });
  return socket;
}
```

export function previewStartPlan(call: CallFacts): ApprovalPlan {
  const verdict = decide({
    mode: call.rules.approvalMode,
    category: "edit",
    tainted: false,
    external: false,
  });
  if (verdict.decision === "block")
    return { outcome: "block", reason: verdict.why, modelReason: READ_ONLY_REASON };
  if (verdict.decision === "allow" && !call.rules.readOnlyPreset)
    return { outcome: "allow", reason: "preview_start: commands run in this mode" };
  return {
    outcome: "ask",
    title: "pap: start a preview?",
    reason: PREVIEW_START_REASON,
    answers: ["deny", "once"],
    grantable: false,
  };
}
