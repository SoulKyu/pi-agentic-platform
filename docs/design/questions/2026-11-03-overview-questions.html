Lot 7 · Inspiré du board de rerun · Tour 1 : le fonctionnel

12 questions sur la vue d'ensemble

Un écran qui répond à « qu'est-ce qui tourne, qu'est-ce qui m'attend, combien ça coûte » pour tous les agents et toutes les boxes projet. Chaque question a une reco ; « Appliquer toutes les recos » remplit tout. Une note libre par question si tu veux nuancer. Les maquettes viennent au tour 2, à partir de tes réponses.

Ce qui existe déjà (le nouvel écran s'appuie dessus, sans le remplacer)

SurfaceCe qu'elle montreCe qui manque pour une vue d'ensemble

Tasks boardUne colonne par projet et par agent : déclencheurs, cartes de tâches, coût du jour.Centré automatisation : ni sessions interactives, ni phase des boxes, ni mémoire.

Q4 · L'unité affichée

Q9 · Ce qu'on peut faire depuis l'écran

A · Ouvrir (clic = l'onglet de l'agent, du projet ou de la tâche) + démarrer / arrêter une box + arrêter une tâche ; « Répondre » ouvre l'item dans l'InboxrecoArrêter une box qui travaille demande confirmation. Les réponses restent à un seul endroit.
B · Lecture seule + ouvrirLe plus simple ; il faut aller ailleurs pour libérer de la mémoire.
C · A + répondre aux questions et approbations sur placeDoublon de l'Inbox et du thread.

Q10 · Owner et membres

A · Un membre voit ses boxes ; l'owner voit tout, groupé par personnerecoLa mémoire est partagée : l'owner doit voir qui la prend. Il voit déjà le budget de chaque membre ; un membre ne voit jamais les boxes des autres.
B · Chacun ne voit que ses boxes, owner comprisLe bandeau de capacité devient trompeur pour l'owner.
