Round 1: quelle direction de marque pour pi-agentic-platform ?

Quatre directions volontairement éloignées, chacune adossée à un design system pensé pour les interfaces IA. L'écran de droite est le même dans les quatre : rail d'agents, lanes, transcript avec raisonnement, outil en cours, demande d'approbation, composer. Seule l'identité change.
